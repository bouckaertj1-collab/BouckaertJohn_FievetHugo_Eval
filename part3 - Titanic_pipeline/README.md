# Partie 3 - Pipeline Titanic

## Objectif

Ce notebook présente la conception complète d’un modèle de prédiction appliqué au dataset Titanic.

L’objectif est de regrouper dans un seul pipeline les étapes principales :
- préparation des données brutes ;
- prétraitement ;
- sélection des variables ;
- entraînement du modèle final ;
- évaluation des performances.

## Fichiers du projet

- `Titanic_Final_Pipeline_Bouckaert_Fievet.ipynb` : notebook principal contenant le pipeline complet.
- `Titanic Dataset.csv` : dataset utilisé pour l’entraînement et l’évaluation.
- `requirements.txt` : librairies nécessaires pour exécuter le notebook.

## Dépendances

Le notebook utilise les librairies Python suivantes :

- pandas
- numpy
- scikit-learn
- matplotlib

Ces librairies doivent être installées dans l’environnement Python utilisé pour exécuter le notebook.
